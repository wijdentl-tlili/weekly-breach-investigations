# 🔐 Weekly Breach Investigations

> **Weekly Breach Method™**
> One real-world breach investigated, mapped to MITRE ATT&CK, and documented every week.

---

## What this is

Every week I pick one real cybersecurity breach, analysing it, and publish a structured incident report. Each report follows the same professional template.

The goal: build a public portfolio that demonstrates practical threat analysis, MITRE ATT&CK mapping, detection engineering, and analyst thinking — one investigation at a time.
